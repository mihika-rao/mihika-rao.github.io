WHY THIS PROJECT

Classification is useful when you can inspect the rule.

The prototype intentionally does not use an opaque model. Every score comes from a visible dictionary of terms, so false positives are debuggable.

A production version could add stemming, embeddings, learned weights, title normalization, and a real corpus. But for a portfolio prototype, the more interesting product choice is making the explanation legible: why did the tool call this a product-analytics role?
