# Between words — Indian languages learning lab

An independent portfolio by Mihika Rao: three working prototypes about context-sensitive Hindi learning, Devanagari decoding, and human review of educational content.

## Add to your existing GitHub Pages site

1. Upload `indian-languages-lab.html` to the root of your website repository.
2. Add this link to your portfolio navigation or projects section:

```html
<a href="indian-languages-lab.html">Between words: Indian languages learning lab</a>
```

The page is self-contained. It needs no package installation, API keys, build service, database, or external assets. Do not replace your existing `index.html`. Open the HTML directly in a browser for a local preview. GitHub Pages will serve it using the repository's existing deployment settings.

## What is included

- **You, in Context:** 12 scenario and agreement items in Notice, Practice, and Transfer stages; optional transliteration; contextual explanations; first-attempt practice scores.
- **A Small Sign, a New Sound:** interactive consonant/vowel-sign builder and 12 decoding items; explicit separation of script recognition from vocabulary and pronunciation.
- **Before It Becomes a Lesson:** six constructed editorial fixtures, six-dimensional rubric, rationale capture, approval gate, and downloadable review log.
- On-page curriculum rationale, cultural and linguistic boundaries, proposed learner studies, review operations, linked references, and content/checklist exports.

`content.json` is a readable copy of the embedded lesson data. Editing it alone does not change the page. To regenerate, edit `source/build.py` (data) or `source/template.html` (page), create `source/dist`, and run `python3 source/build.py`. Copy the generated `source/dist/indian-languages-lab.html` into your website. The generated `index.html` is only a local preview alias.

## Evidence and review status

These are source-informed, AI-assisted portfolio prototypes. No affiliation with Duolingo, independent educator approval, participant study, measured learning improvement, or production deployment is claimed. Review examples are deliberately constructed fixtures, not observed model outputs or a model-quality benchmark. The demo performs no live AI generation. Its prompt brief describes a proposed workflow.

The page distinguishes descriptive source material from original design proposals. Hindi examples require independent educator review before use in a course. Kannada is discussed as a future design extension; a Kannada course has not been built. Malayalam is listed at beginner level.

## Data and privacy

Answers and editorial reviews exist only in browser memory and clear on refresh. Export the review log to keep it. There are no analytics, cookies, remote form submissions, or API calls. Exported logs contain any notes typed by the reviewer; avoid entering private learner information.

## Verification

Desktop visual inspection and browser interaction checks covered lesson feedback, the vowel-sign builder, blocked approval with unresolved rubric dimensions, and saving a revision decision. Responsive CSS is included; a separate mobile-device review is still advisable before publishing. No learning efficacy testing has been performed.

## Suggested next work

Recruit and compensate Hindi educators and speakers from relevant communities to independently review examples, accepted alternatives, and explanations. Pilot with 5–8 adult beginners to identify usability problems; use new transfer items and delayed checks rather than treating completion as learning. Publish findings and revisions only after collecting them. The on-page plan explains these steps in more detail.

Sources are linked beside the claims they support and collected at the end of the page. Reference pages and source text are not redistributed.
