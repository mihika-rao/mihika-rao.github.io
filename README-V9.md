## Privacy / provenance
- DSBK uses only aggregate published results and blank survey instruments. The student-level spreadsheet is not included in the site package.
- The research-model playground uses published/result-level values but an illustrative re-rendering of points rather than raw publication data.
- Should We Ship It? uses explicitly synthetic experiment data.
- The Coffee Problem uses an explicitly illustrative hand-built sample price table, not a market price index.
- The Job Posting Translator is a transparent rule-based prototype; no external job-description corpus is bundled.
