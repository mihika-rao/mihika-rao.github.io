What changed
- One shared navigation system across every page.
- One shared editorial visual language: warm paper, black rules, Georgia display type, sans-serif UI type.
- Consistent project accent colors across Home, Projects, and project pages.
- Home wordmark still changes moods, but its footprint is constrained so it does not collide with the page.
- Home featured work uses categories rather than mismatched project numbers.
- Projects page uses consistent descriptions and the same Open project CTA.
- NovaCards, Evidence that moved, and Constellation keep their existing interactions but now share the same shell.
- Colouring Outside the Lines keeps its book/digital experience but uses the same site navigation and spacing system.
- 36 Days of Type keeps the sparse gallery, with the same site shell and a quieter intro.
- Fog, Funds & Ferns is fully rebuilt as a visual San Francisco property-game project:
  * classic square board structure
  * extremely expensive SF property prices
  * Free Parking corner fixed so all text fits
  * 6 property deed cards
  * 12 Angel Round cards
  * 12 Group Chat cards
  * SF banknotes and player pieces
  * no generic design-system/palette section

GitHub upload
1. Unzip this folder.
2. Upload EVERYTHING inside the folder to the root of your GitHub Pages repo.
3. Replace the existing files when GitHub asks.
4. Keep 01-A.png through 36-9.png in the root; 36-days-type.html points to those flat paths.
5. Commit.
6. Wait for the Pages deployment to finish, then hard-refresh the live site (Cmd+Shift+R on Mac).
