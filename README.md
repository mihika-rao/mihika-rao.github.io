# Mihika Portfolio — GitHub Pages flat-root package

This package is intentionally FLAT so it works when GitHub uploads the files individually.

Upload every file in this folder directly to the repository root.
Do not put the files inside another folder.

The 36 Days of Type images (01-A.png ... 36-9.png) live in the repository root,
and `36-days-type.html` references them directly.

GitHub Pages should publish from:
Settings → Pages → Deploy from a branch → main → /(root)
