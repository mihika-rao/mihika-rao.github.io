PROPERTY DEEDS

The rent is the punchline.

Property cards keep the familiar deed-card structure: a coloured neighbourhood band, purchase price, rent ladder, and one tiny line of local commentary.

I kept the spread visual-first so the cards read like game components rather than a design-system exercise.

but make it local.

Chance becomes Angel Round.

Each deck gets its own graphic language and a full set of cards so the project feels like a complete game, not just a board mockup.
